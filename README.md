# Flappy Bird – Unity Recreation

A recreation of the classic Flappy Bird game, developed independently using **Unity and C#**. The project recreates the core gameplay while introducing additional mechanics, including special power-ups, enemies and custom bird movement using Bezier curves.

## Features

- **Player movement:** Control the bird's movement and navigate through obstacles.
- **Bezier curve movement:** Implemented curved movement to control the bird's jumping and falling behaviour.
- **Obstacle generation:** Pipes spawn and move across the screen, creating challenges for the player.
- **Collision detection:** Detect collisions between the bird, obstacles and other game objects.
- **Scoring system:** Track the player's score as they progress through the game.
- **Power-ups:** Additional gameplay mechanics that provide special abilities.
- **Enemies:** Extra obstacles that introduce further challenges.
- **Increasing difficulty:** Gameplay becomes more challenging as the player progresses.
- **Game states:** Includes a main menu, game-over screen and restart functionality.

## Technologies Used

- **C#** – Game logic and functionality.
- **Unity** – Game engine and development environment.
- **Git / GitHub** – Version control and project hosting.

## Getting Started

### Opening the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/evleen-m/NEAProject.git
   ```

2. Open **Unity Hub**.
3. Select **Add Project from Disk**.
4. Navigate to the cloned `NEAProject` folder and open the project.
5. Open the main game scene in the Unity Editor.

### Building the Game

1. In Unity, navigate to **File → Build Profiles** (or **File → Build Settings** in older Unity versions).
2. Select your target platform, such as Windows, macOS or Linux.
3. Make sure the main game scene is included in the build.
4. Select **Build**.
5. Choose an output folder and wait for Unity to generate the executable.

Once the build is complete, run the generated executable to play the game.
